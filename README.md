# What is Kefir?
Kefir is a mini banking core, with a simplified approach for educational purposes only.

## Setup

Building this project requires using a PostgreSQL database with Kefir core tables (Environment image currently is WIP).
Initial development created on a MacBook Air M2 32 GB using Java 17 with IntelliJ IDEA CE

## Dependencies

This project uses Hibernate to connect to the database and perform operations. 

## Bundles

This project use Gradle for maintaining the bundles.

## Philosophy

The point of this software is to keep it simple in order to understand better things 
that we already know and learn new ones. I encourage you to add more modules to the core
using the same methodology in every object. Have fun!
